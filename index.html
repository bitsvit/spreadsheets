Будова діаграми в Google Таблицях

Пригадай: Назва діаграми зазвичай розташована зверху. Легенда пояснює, якому кольору відповідає кожен ряд даних. Вісь категорій (горизонтальна, X) містить назви об'єктів (наприклад, місяці або предмети), а Вісь значень (вертикальна, Y) — числові показники. Усередині осей знаходиться Область побудови з Рядами даних (стовпцями).

Уважно розглянь зразок стовпчастої діаграми з Google Таблиць. Підпиши кожен позначений цифрою (1–6) елемент діаграми, обравши правильну назву зі списку.

Обери доречний тип діаграми

  • Стовпчаста (гістограма) — найкраще підходить для порівняння кількості або значень різних об'єктів чи категорій.
  • Секторна (кругова) — показує частку (відсоток) кожної складової від одного цілого (100%).
  • Лінійна (графік) — наочно демонструє зміну величини з плином часу (динаміку за дні, місяці, роки).

Прочитай три життєві ситуації семикласників та обери для кожної найкращий тип діаграми у Google Таблицях.

Симулятор Google Таблиць: Створи діаграму

Покрокова інструкція:
  1. Виділи діапазон клітинок A1:B6 (включаючи заголовки стовпців «День тижня» та «Кроки», але без рядка «Всього за тиждень», щоб підсумок не спотворив порівняння днів!).
  2. Натисни у меню Вставити → Діаграма (або кнопку панелі інструментів).
  3. У панелі Редактор діаграм обери тип Стовпчаста діаграма та введи заголовок: Активність за тиждень.

🎯 Завдання:

Оленка вела облік пройдених кроків за 5 навчальних днів. Побудуй діаграму для порівняння її активності по днях:

  • Крок 1: Виділи правильний діапазон клітинок таблиці (підказка: чи потрібен рядок «Всього» для порівняння днів?).
  • Крок 2: Натисни Вставити → Діаграма.
  • Крок 3: Обери тип Стовпчаста та встанови назву діаграми «Активність за тиждень».
